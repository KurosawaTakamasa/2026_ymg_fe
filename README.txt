基本情報技術者試験 科目B CBT演習
==================================

■ 使い方
  1. このフォルダ（kamokuB_cbt）を丸ごとPCに保存します。
     index.html と data フォルダは必ず同じ場所に置いてください。
  2. index.html をダブルクリックすると，ブラウザで問題選択画面が開きます。
     （インターネット接続は不要です。Microsoft Edge や Google Chrome での利用を想定しています）
  3. 解きたいセットの「開始」→ 試験時間を確認して「試験開始」を押します。

■ 収録している問題（全130問）
  ・お試しセット ……………… 5問（アルゴリズム4・セキュリティ1）
  ・5問ミニテスト 第1～5回 … 各5問（アルゴリズム4・セキュリティ1，標準25分）
  ・本番形式 第1～5回 ……… 各20問（問1～16 アルゴリズム，問17～20 セキュリティ，標準100分）
  ※ すべてオリジナル問題です。アルゴリズムの問題は，プログラムの処理を
    別の言語で再現して正解を確認しています。

■ 画面の機能
  ・付箋 ………… 見直したい問題に印を付けます（左の問題一覧に表示）
  ・文字サイズ … 画面右上の「小・中・大」で切り替えます
  ・中断 ………… 試験をやめて問題選択画面に戻ります（解答は消えます）
  ・採点後は，結果一覧の下に全問の詳細解説が表示されます。
    「不正解の問題だけ」に絞り込んだり，「問題文を見る」で問題と解説を並べて確認したりできます。
  ・前回の結果（正解数と日付）は，そのPCのブラウザにだけ記録され，問題選択画面に表示されます。
    結果がどこかに送信されることはありません。

■ 問題の追加方法
  1. data フォルダの _template.js をコピーし，半角英数字の名前を付けます（例：my-01.js）。
  2. ファイルをメモ帳などで開き，ファイル内の説明に従って問題を書き換えます。
     （文字コードは UTF-8 のまま保存してください）
  3. data フォルダの sets.js を開き，一覧の最後に次の1行を追加して保存します。
        'my-01.js',
  4. index.html を開き直すと，問題選択画面の「追加した問題」に表示されます。
     group を "mini" や "full" にすると，それぞれの欄に表示されます。
  ※ 書き方に誤りがあると，問題選択画面の下に赤字で表示されます。

■ 学生に配布するとき
  フォルダごとZIPに圧縮して配布してください。展開してから index.html を開くよう伝えてください。
  （ZIPを展開せずに中の index.html を開くと，問題ファイルを読み込めないことがあります）
